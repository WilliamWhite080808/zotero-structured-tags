# 1.0.2 / Version 1.0.2

## 中文说明

- 增加位于 Zotero 数据目录的独立 SQLite 镜像数据库和修改历史。
- 插件编辑以及 Zotero 原生标签修改会实时同步到本地镜像。
- 版本升级前扫描已有数据，使用多层置信度规则智能匹配字段。
- 仅自动迁移高置信度结果；不确定结果不会覆盖原数据。
- README、CHANGELOG、发布指南和 Release 说明改为中英双语。

## English Notes

- Adds a separate SQLite mirror database and audit history in the Zotero data directory.
- Mirrors plugin edits and native Zotero tag changes to the local database in real time.
- Scans existing data before upgrades and matches fields with multi-layer confidence rules.
- Automatically migrates only high-confidence results and never overwrites source data for uncertain matches.
- Makes the README, changelog, publishing guide, and release notes bilingual.

## 安装 / Installation

下载 `structured-tags-1.0.2.xpi`，在 Zotero 中选择“工具 → 插件 → Install Plugin From File…”，然后重启 Zotero。已有 Zotero 原生标签保持不变，首次启动会建立本地镜像。

Download `structured-tags-1.0.2.xpi`, choose **Tools → Plugins → Install Plugin From File…** in Zotero, and restart Zotero. Existing native Zotero tags remain unchanged; the local mirror is created on first startup.
