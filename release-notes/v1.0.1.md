# 1.0.1 / Version 1.0.1

## 中文说明

- 修复 Zotero 10 中“字段与选项设置…”无法打开的问题。
- 修复 Zotero 10 中“编辑所选文献…”无法打开的问题。
- 编辑窗口改用已注册的受信任插件地址加载。
- 窗口打开失败时显示明确的错误信息。
- 增加管理窗口入口的回归测试。

## English Notes

- Fixes the **Field and Option Settings…** window in Zotero 10.
- Fixes the **Edit Selected Items…** window in Zotero 10.
- Loads editor windows through a registered privileged plugin URL.
- Shows an explicit error when an editor window cannot be opened.
- Adds regression coverage for the management-window entry point.

## 安装 / Installation

下载 `structured-tags-1.0.1.xpi`，在 Zotero 中选择“工具 → 插件 → Install Plugin From File…”，然后重启 Zotero。

Download `structured-tags-1.0.1.xpi`, choose **Tools → Plugins → Install Plugin From File…** in Zotero, and restart Zotero.
