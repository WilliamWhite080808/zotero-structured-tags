# 1.0.0 / Version 1.0.0

## 中文说明

- 首个公开版本。
- 提供可配置的 Zotero 原生结构化标签列。
- 支持单选、多选、数值和文本字段。
- 支持单元格编辑、批量编辑和字段配置。
- 支持字段名称、候选选项、排列顺序和显示状态设置。
- 使用通用默认字段，不包含特定研究领域内容。

## English Notes

- First public release.
- Provides configurable structured columns backed by native Zotero tags.
- Supports single-choice, multiple-choice, numeric, and text fields.
- Supports cell editing, batch editing, and field configuration.
- Supports custom names, options, ordering, and visibility.
- Uses general-purpose defaults without exposing a specific research topic.

## 安装 / Installation

下载 `structured-tags-1.0.0.xpi`，在 Zotero 中选择“工具 → 插件 → Install Plugin From File…”，然后重启 Zotero。

Download `structured-tags-1.0.0.xpi`, choose **Tools → Plugins → Install Plugin From File…** in Zotero, and restart Zotero.
