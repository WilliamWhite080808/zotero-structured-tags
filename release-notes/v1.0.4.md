# 1.0.4 / Version 1.0.4

## 中文说明

- 自定义列改用普通文本显示，移除蓝色胶囊背景、边框和悬停底色。
- 多个值以顿号分隔，列较窄时统一省略；继承 Zotero 列表字体及选中颜色。
- 保留单击编辑和完整值提示，现有字段与标签数据继续使用。

## English Notes

- Display custom columns as plain text, removing blue pills, borders, and hover backgrounds.
- Separate values with an ideographic comma and truncate at the cell width; inherit Zotero list typography and selection colors.
- Preserve click-to-edit, full-value tooltips, and existing field and tag data.

## 安装 / Installation

下载 `structured-tags-1.0.4.xpi`，在 Zotero 的“工具 → 插件”中从文件安装，然后重启 Zotero。

Download `structured-tags-1.0.4.xpi`, install it from a file in Zotero's **Tools → Plugins**, and restart Zotero.
