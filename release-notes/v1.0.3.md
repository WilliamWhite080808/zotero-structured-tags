# 1.0.3 / Version 1.0.3

## 中文说明

- 修复 Zotero 10 启动后一直停在“正在检查数据库完整性”的问题：插件镜像库的未清空 WAL 会误入主库恢复界面，而检查成功后遮罩仍保留。
- 镜像库改为外部数据库模式打开，独立检查完整性，并在退出时等待写入完成、关闭连接。
- 初始化失败时释放连接，保留原文件；列和菜单先于可选镜像初始化。
- 沿用原有 `structured-tags.sqlite`，保留原生标签、字段配置和变更历史。
- 增加 WAL 场景连接模式、初始化失败和应用退出回归测试。

## English Notes

- Fixes Zotero 10 getting stuck on “Checking database integrity” after startup: an existing mirror WAL entered main-library recovery UI and left its overlay visible even after a successful check.
- Opens the mirror in external-database mode, independently checks integrity, and drains writes and closes the connection on exit.
- Releases failed connections without deleting files and registers columns and menus before optional mirror initialization.
- Reuses `structured-tags.sqlite`, preserving native tags, field settings, and audit history.
- Adds regression tests for WAL-safe connection mode, initialization failure, and application shutdown.

## 安装 / Installation

下载 `structured-tags-1.0.3.xpi`，在 Zotero 中选择“工具 → 插件 → Install Plugin From File…”，安装并重启。如果此前手动停用了插件，请重新启用。

Download `structured-tags-1.0.3.xpi`, choose **Tools → Plugins → Install Plugin From File…**, install, and restart Zotero. Re-enable the plugin if it was previously disabled manually.
